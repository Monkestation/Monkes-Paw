/proc/add_minimap_blipCreate a minimap blip on the z-level in question, object is optional, and will tie the blip to the object in question, and will clean up itself if the object in question is deleted
/proc/get_minimap_blipReturns the minimap blip with the passed tag that is tracking the passed object, if there is one
/proc/remove_minimap_blipRemoves and deletes the minimap blip with the passed tag that is tracking the passed object
/proc/get_minimap_blips_in_areaReturns minimap blips matching a tag that are within distance tiles of target_turf on the same z-level.
