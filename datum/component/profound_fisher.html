profound_fisher
/datum/component/profound_fisher

component that allows player mobs to play the fishing minigame without a rod equipped, non-player mobs will "pretend" fish

Vars

delete_rod_when_deletedWether we should delete the fishing rod along with the component or replace it if it's somehow removed from the parent
our_rodthe fishing rod this mob will use

Procs

begin_fishingStarts fishing on the target with the integrated fishing rod
on_dropStops the dropper from fishing with their bare hands
on_equipLets the wearer fish with their bare hands when the parent is worn as gloves
on_examineTells the examiner how to open the integrated fishing rod interface
on_requesting_context_from_itemAdds the screentip to open the rod UI when held with an empty hand
on_rod_movedHandles replacing the fishing rod if somehow removed from the parent movable if delete_rod_when_deleted is TRUE, otherwise delete the component.
on_unarmed_attackFishes on the target when attacking it unarmed, if it's a fishing spot
open_rod_menuOpens the UI of the integrated fishing rod
pre_attackFishes on the target instead of attacking it, if it's a fishing spot
pretend_fishFakes a whole fishing session for npc mobs, waiting a bit before spawning the reward
should_fish_onReturns whether the user should start fishing on the target instead of interacting with it
stop_fishingRemoves the profound fisher trait once the fishing is over
